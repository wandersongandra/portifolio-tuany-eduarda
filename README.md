## Placeholders (trocar quando a cliente enviar)

Edite `src/config.ts`:

- `whatsapp` — número E.164 (ex.: `5531999999999`) e `whatsappIsPlaceholder: false`
- Foto profissional no hero (hoje SVG ilustrativo)
- Bairros / cobertura exata
- Domínio real (`site.url` + `astro.config.mjs`)
